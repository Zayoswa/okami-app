# OKAMI WEBB APP

### General
Okami Web App es una aplicacion web responsiva para el estudio de okami. Su Funcion es ser una pagina de gestion
de espacios y trabajos para los tatuadores del estudio. Debido a que los puntos de dolor sufridos en el trabajo son la falta
de centralizacion de informacion y eventos dentro del mismo estudio

La App busca:

- Centralizar Fechas e informacion de Clientes
- Funcion de Calendario
- Funcion de Reservas de Espacios 
- Registro Historico de Tatuajes realizados
- Sistema de Roles de usuarios con distintos niveles de visibilidad y accion

Se espera que con esto el trabajo tanto repetitivo como manual se baje la cantidad de consultas fisicas hacia el administrador
